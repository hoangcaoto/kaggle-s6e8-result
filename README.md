# Kaggle Playground Series S6E8 — Predicting Smartphone Addiction

I participated in the [Predicting Smartphone Addiction competition](https://www.kaggle.com/competitions/playground-series-s6e8). The task was to predict the binary `addicted_label` from tabular smartphone-use data, evaluated by ROC-AUC.

## Final standing

- **Private leaderboard (final): 244th**, ROC-AUC **0.97101**
- **Public leaderboard: 252nd**, ROC-AUC **0.97126**

This repository is only a record of participation and results. It contains no source code, competition data, model files, predictions, or submissions.
